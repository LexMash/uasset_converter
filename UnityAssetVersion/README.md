# Uasset Converter — версия для Unity (Editor Asset)

Самодостаточная сборка конвертера Unreal → Unity: **весь тул целиком** (Python-пайплайн + C#-окно редактора) лежит в одной папке `UassetConverter/`. Кладёшь её в свой Unity-проект — и запускаешь экспорт/конвертацию прямо из редактора, без отдельного репозитория и без ручного ввода путей к скриптам.

Это копия основного инструмента. **Python-код и логика пайплайна идентичны** оригиналу — меняются только то, как C#-окно находит `convert.py` (теперь рядом с собой) и путь для выходных файлов.

## Что нужно

- **Unity** 6000.x или 2022.3 LTS с URP или HDRP.
- **Python 3** установлен в системе, с пакетами `numpy` и `Pillow`. Сам интерпретатор в ассет не входит — используется системный.
- **Unreal Engine 5.8** — для шага экспорта (используются нативные экспортёры движка).

## Установка

1. Скопируй папку `UassetConverter/` в `Assets/` своего Unity-проекта:

   ```
   <ТвойПроект>/Assets/UassetConverter/
   ```

2. Дай Unity скомпилировать C#. В меню появится **Tools → Uasset Converter → Convert**.

3. Открой окно. Путь к конвертеру (`convert.py`) подставится **сам** — он лежит внутри той же папки. Нажми **Autodetect** рядом с полем Python: окно найдёт системный Python 3. Если не хватает `numpy`/`Pillow`, окно покажет точную команду `pip install …` — выполни её один раз.

## Как пользоваться

1. Укажи путь к проекту Unreal (`.uproject`), папку движка и scope (`test` для пробы).
2. **Export** — экспорт ассетов из Unreal (прогресс идёт в окне).
3. **Convert & Import** — транспиляция шейдеров, постобработка и импорт результата в проект.

Отдельные шаги (Export / Shaders / Postprocess) и «Import only» доступны кнопками там же.

## Куда что пишется

- **Выходные файлы** (`output/`) — в `<ТвойПроект>/UassetConverterOutput/`, **вне** `Assets/`, чтобы не засорять проект промежуточными данными. Путь настраивается в окне.
- **Готовые ассеты** — в `Assets/UassetConverted/` (настраивается).
- **config.json** — рядом со скриптами внутри `Assets/UassetConverter/`. При изменении настроек в окне Unity может кратко переимпортировать этот файл — это нормально.

## Shader Graph-бэкенд отключён

Основной вывод шейдеров — **HLSL** (`.shader` для URP), он работает из коробки. Второй бэкенд, собирающий `.shadergraph` через API пакета Shader Graph (`ShaderGraphBuilder.cs`), написан против старого API, где типы `AbstractMaterialNode`/`GraphData`/`BlockNode` были `public`; в Shader Graph 12+ (Unity 6000.x / 2022.3) их сделали `internal`, поэтому эта подсборка **не компилируется** (`CS0122`). Чтобы проект не сыпал ошибками, она отключена: в её asmdef добавлен define-constraint `UASSET_SHADERGRAPH_BACKEND`, которого нет в проекте.

Последствий для URP/HLSL нет: `ShaderGraphWriter` без реализации просто ничего не пишет (это не ошибка). Если понадобится вывод именно в Shader Graph (например, для HDRP) — бэкенд нужно чинить отдельно (переписать на публичный API или на прямую генерацию `.shadergraph` JSON), после чего включить его, добавив `UASSET_SHADERGRAPH_BACKEND` в Project Settings → Player → Scripting Define Symbols.

## Язык интерфейса

Локали общие для C# и Python (`unity/com.uasset.converter/Editor/Locales/`). Переключение языка в окне сохраняется в конфиг, так что отчёты (`unsupported.md`) собираются на том же языке.
